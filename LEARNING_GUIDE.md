# Learning guide: study these in order

Do not try to memorise every line of code. Understand the pipeline.

## 1. Python foundations
- Variables, strings, lists and dictionaries
- Functions and imports
- Reading CSV files
- Exceptions and file paths

## 2. Data handling
- Pandas DataFrame and Series
- Missing values
- Filtering rows
- Train/test split
- Class distribution

## 3. NLP foundations
- What is Natural Language Processing?
- Tokenisation
- Stop words
- Unigrams and bigrams
- TF-IDF and why text must be converted into numbers

## 4. Machine Learning
- Supervised learning
- Classification
- Logistic Regression
- Linear Support Vector Machine
- Training versus prediction
- Overfitting and generalisation

## 5. Evaluation
- Confusion matrix
- Accuracy
- Precision
- Recall
- F1-score
- Macro F1 and class imbalance
- Why a holdout test set should not be used to tune the model

## 6. Application
- What is Streamlit?
- Loading a saved model with Joblib
- Single prediction
- Batch prediction
- Why human review is important

## Interview honesty
Be ready to explain:
- The dataset source, size, categories and limitations.
- Why TF-IDF was used.
- Why Logistic Regression was selected for the dashboard.
- What the displayed model score means and does not mean.
- How the model was evaluated.
- Why routing is a separate illustrative rule rather than a model prediction.
